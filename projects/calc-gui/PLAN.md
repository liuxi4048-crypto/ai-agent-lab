# calc-gui Project Plan

## Goal
Create a tkinter-based calculator GUI with buttons for digits 0-9, operators (+, -, *, /), equals (=), and clear (C). Display formula and result, show "Error" on invalid input.

## Files
- calc.py: Main application.

## Features
- Display area for input and results.
- = evaluates expression (shows "Error" on error).
- C clears display.
- Uses tkinter, mainloop blocks execution.

## Verification
- Run `python -m py_compile calc.py` for syntax check.
