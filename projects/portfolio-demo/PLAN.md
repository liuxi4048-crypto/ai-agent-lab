# PLAN for stats.py

## Requirements
- Create a Python script `stats.py` that calculates sum, average, max, and min of a numerical list.
- The list should be hardcoded (e.g., `[10, 20, 30, 40, 50]`).
- Output should display each value clearly.

## Files
- `stats.py`: The main script.

## Verification Command
- Run `python stats.py` and check output matches expected values (sum=150, avg=30.0, max=50, min=10).
