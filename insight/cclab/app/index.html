コンテキスト可視化

モデルに毎回どれだけの情報を送り、そのうちどれだけをキャッシュで安く済ませたか。

このグラフの読み方
  • 棒1本 = モデルへの問い合わせ(API 呼び出し)1回。左から時間順。下の目盛りはセッション開始からの経過時間。
  • 棒の高さ = その回にモデルへ送った量(入力トークン)。Claude Code は毎回それまでの会話全体を送り直すため、作業が進むほど右肩上がりになる。
  • 色 = 送った量の内訳。緑: 前回と同じ部分をキャッシュから再利用(安い)。黄: 今回新しく増えた部分をキャッシュへ書き込み。青: キャッシュを使わず処理(ほぼ0)。
  • 下段の紫 = モデルが書いた量(出力トークン、思考を含む)。入力とは桁が違うので別の目盛りで表示。
  • ①は最初の1回(何もしなくても送られる固定費)、⚠は黄色が急に大きい回(キャッシュの作り直しの疑い)。
